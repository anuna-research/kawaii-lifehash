USE IT IN YOUR APP

A small component, ready to embed.

Get the code from the repository.
The markup follows your seed and mood.

Clone the repository

git clone https://git.anuna.io/anuna-research/kawaii-lifehash.git

Markup

<lifehash-avatar seed="researcher:42"
  state="thinking" size="128"
  aria-label="Research companion"></lifehash-avatar>

Import once

import 'kawaii-lifehash/component';
import 'kawaii-lifehash/styles.css';

Connect to a task

const agent = document.querySelector('lifehash-avatar');

async function runWithAgent(task) {
  agent.state = 'thinking';
  try {
    const result = await task();
    agent.state = 'success';
    return result;
  } catch (error) {
    agent.state = 'error';
    throw error;
  }
}

Change seed to generate an identity. Change state to set its expression. The avatar renders automatically.
